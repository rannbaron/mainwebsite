How to Use the Riemann Sums Explorer

  • Type your function into the box at the top. Use implicit math (like 2x).
  • Smart Information Box: The stats box automatically dodges your rectangles and curves! If all 3 graphs are active, it securely locks itself into the empty bottom-left corner.
  • Smart Bounds: The bounds boxes accept math! You can type numbers like 5, fractions like 1/2, or trig values like 2pi.
  • Precision Control: Adjust the "Sig Figs" box to change how many significant digits are displayed in the area calculations.
