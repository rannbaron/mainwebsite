⚙️ Infrastructure & API Architecture

Modular Python tools located at ~/src/gradescopetools/ driving automated synchronization, verification, and email dispatch.

gradescope_tasks.py Core Client

REST API wrapper interfacing with Gradescope endpoints. Extracts session cookies and CSRF tokens, reads rubric outlines, submits batch extensions, and schedules assignment release dates.

duke_mail_merger.py Graph REST

Direct Microsoft Graph API OAuth2 mail engine. Uses cached Duke credentials (~/.duke_token_cache.bin) to send formatted HTML communications and PDF attachments from rb6@duke.edu.

student_status_reporter.py Analytics

Roster-wide mastery tracker calculating total Passed vs. No-Pass assignments, evaluating semester-end extension eligibility, and surfacing critical warning alerts.

quiz_retake_manager.py Retake Core

Automates the Quiz Retake lifecycle: creates retake assignments, enforces the Download Delay Rule (1 wk + 1 hr), and creates duplicate Quiz <N> late retake items one year post-term.

Hourly Scan Verification PDF Auditing

Runs every hour for active assignments. Parses JSON submission objects, tests page count against official PDF templates, and detects inverted pages, triggering instant 12-hour extensions and mobile scanner guidance.

update_grades.py Gradebook Sync

Parses raw Gradescope CSV exports into Canvas-compliant gradebook matrices, recalculates weighted components, and synchronizes finalized scores with official Duke registrar records.

⚖️ Strict Instructional Governance & Guardrails

Mandatory policy guardrails hardcoded into all scripts, cron workflows, and AI pair-programming agents.

Guardrail 1 STRICT PROHIBITION

Non-Current Assignments Absolute Rule

NEVER send any notifications whatsoever regarding non-current assignments to any students in any section. Deadlines, extensions, submission window modifications, and student notifications MUST ONLY occur for CURRENT assignments unless explicitly instructed by Rann. All extensions on non-current assignments must remain removed.

Guardrail 2 PERMANENT EXCLUSION

Permanently Dropped Students Policy

Isaiah Nwoko (isaiah.nwoko@duke.edu), Marissa Payne (marissa.payne@duke.edu), and Emmanuela Kumi (emmanuela.kumi@duke.edu) have been permanently removed from Math 105L. They must NEVER receive any notifications, extensions, retakes, or reports across all pipelines.

Guardrail 3 SEMESTER END

Semester-End Extensions Policy

Extensions until undergraduate classes end (Friday, December 4, 2026 at 11:59 PM) are granted ONLY to students who have either >2 quiz NPs or >4 worksheet NPs. In all such cases, NEVER email students; only email Rann (rb6@duke.edu).

Guardrail 4 1-YEAR POST TERM

Quiz Late Retake Architecture

For quizzes, NEVER extend deadlines on original quizzes. Instead, duplicate the original quiz as Quiz <N> late retake, set available Dec 4–5, 2027 (1 year post-term), and clear all prior extensions on the original quiz.

Guardrail 5 1 WK + 1 HR DELAY

Quiz Retake Score Download Delay Rule

Quiz retake scores are not downloaded to rawscores/ or released to students until one week and one hour after the retake assignment first opens. This delay is guarded programmatically in gradescope_tasks.py by is_quiz_retake_eligible_for_download().
